# EKSEN - surum deposu

Bu depo **kaynak kod icermez**. Yalnizca yayimlanmis surumlerin
imzali surum dosyasini ve paketlerini tasir.

Kaynak kod ayri ve **ozel** bir depodadir.

## surum.json

Program bu dosyayi okuyup yeni surum olup olmadigina bakar.
Dosya **imzalidir**: imzayi dogrulayan acik anahtar programin
icine gomuludur ve degistirmek icin programi yeniden derlemek
gerekir.

Imzasi dogrulanmayan bir surum dosyasi **kurulmaz**.
